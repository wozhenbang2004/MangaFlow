# 成人漫画体验重做 · 2026-11-19

基线：`07bf1b85f96b9de9276fe04278e9499d20603e86`。用户要求按完整审美库系统重做成人漫画全部界面与交互。本次沿现有普通／成人内容身份及独立书架、来源能力、搜索与阅读路径实施；Android 手机／平板与 Windows 是目标端。

主线：从侧栏进入成人分区 → 首屏识别作品和当前来源 → 在作品、作者或标签中找书 → 详情选章／继续阅读 → 回到原筛选和位置。书架把本机收藏、站点收藏与账号操作分清；账号失败保留已有内容并提供对应恢复入口。视觉采用内容主导的连续画布、清晰封面、安静选中态、少量玻璃导航与按需展开的毛玻璃面板。

## 开工前的 15 项设计决定

下表在 UI 代码修改前建立。参考为已阅读的审美库原文和基线中的实际采用代码；这些决定是本次产品适配，不代表已经通过用户审美验收。

| 系统 | 决定与落点 | 选择理由、参考与实际取用 | 验收动作与条件 |
| --- | --- | --- | --- |
| 配色与表面关系 | 来源、栏目、筛选用正文色与局部低对比选中底；登录和错误只在对象行表达；封面保持原色。 | 审美库根页「跨项目配色审美决策」先定焦点；沿用 Theme / MotionTabs 的 onSurface 层级，避免整排蓝色链接。 | 深浅主题切来源、筛选与登录，当前项通过文字／勾选可辨。 |
| 形状与圆角 | 作品封面沿用 mangaCoverCard；源选项只保留一个语义容器，菜单行内不再套框。 | CoverCardSurface.kt 的 diffuse shadow + image clip；空间系统「分组与套卡」要求边界对应对象。 | 长源名、标签、多行错误不被圆角裁切。 |
| 空间与密度 | 首屏为作品，源上下文一行、低频动作收拢；手机保留三列，宽屏按现有列数适配；书架工具与内容共用轴线。 | [空间与密度](https://chatgpt.com/space/page_fd2c89948d3c8191b11b87a2de3ed2e4)「固定层预算」「语义分组」；不缩小字号换密度。 | 窄屏、长名称、横屏检查首屏作品与主动作。 |
| 排版与可读性 | 封面标题两行、作者／来源一行次级信息；来源选择行采用主名＋具体状态，去重复状态。 | 现有 WORK_TITLE 与 MaterialTheme typography；空间系统的同角色轴线。 | 长中文、字号放大时标题可读，关键动作不被挤掉。 |
| 组件选择与控件状态 | 少量同级栏目直接用 Ovio MotionTabs；多选项用原有 retained sheet；筛选和标签各自有清楚对象及当前值。 | MotionTabs.kt，Ovio Minimal Liquid Tabs 固定版 81a1bcb；库根页「选择显示模式」并列比较原则。 | 切换、返回、重新打开后选中值与控制器一致。 |
| 动效与过渡 | 保留 MotionTabContent、真实退出后 handoff；推荐区在同一查询内稳定布局，避免封面解码后突然插入大块。 | 现有 beUI/Ovio 采用源码；根页「状态入口与详情连续性」。 | 快速反点、关闭、换源不穿透、不触发旧操作。 |
| 图标与符号 | 常用来源、筛选、刷新、账号使用既有统一线性图标；陌生作用保留短标签；触控命中至少44dp。 | MotionIconButton 与 ChapterSourceLogo 已采用实现；内容系统「图标与可访问名称」。 | 触控和鼠标分别识别动作，名称包括对应来源或作品。 |
| 图像与媒体 | 沿用真实封面和 FeaturedCarousel；推荐布局由真实目录决定，加载／失败保持尺寸；成人卡不用不支持的外站评分。 | FeaturedCarousel.kt 与 CoverCardSurface.kt；原 Material carousel 的内容归属和相邻作品可见关系。 | 断图、慢图和回到列表时封面框、标题、选择位置稳定。 |
| 导航与信息架构 | 成人分区沿独立状态；来源浏览、内容类别、搜索目标与账号归属分别清晰；详情仍走现有阅读器。 | 根页用户主线、空间渐进披露；DiscoverScreen / ContentProfileSourceSheet 已有 source-qualified identity。 | 源→筛选→作品→阅读→返回保住原条件、滚动和分区。 |
| 跨尺寸与输入适配 | 文字可增长，长列表局部滚动；手指图标范围不随封面列数缩小；宽屏不把少量封面拉成海报。 | 空间系统「小屏和文字变化」及 MangaLayout 的现有边界。 | 手机、横屏、宽窗、键盘出现和字号放大检查遮挡。 |
| 阴影、层级与材质 | 导航和临时层沿现有 LiquidGlass / PANEL，作品区连续干净；不在 hazeSource 内增加采样自身的玻璃。 | [材质系统](https://chatgpt.com/space/page_0e1e13313cfc8191b780e4a0e08d8df8)；GlassControlGroup.kt 与 LiquidGlass.kt 的真实角色。 | 亮暗封面背景下正文、浮层和后方输入层明确。 |
| 内容与文案 | 删除“已启用”等无变化重复说明；空态按未选、加载失败、无结果、需登录区分，动作指向实际恢复。 | [内容与文案](https://chatgpt.com/space/page_56060cc5a360819189770972264af5bf)「反馈位置」「先去重复」「真实原因」。 | 断网、无结果、无账号各能看懂下一步，已有作品仍可用。 |
| 交互手感与感知性能 | 源与筛选切换先立即反馈；保留查询缓存和位置；异步能力读取不重置整页／吞掉浏览。 | 现有 motionInputGate / retained owner；空间系统「连续性」与原主线程时间边界。 | 快速切换和慢返回时不误选，不回顶，不重播离场。 |
| 数据可视化与监控 | 每来源错误、收藏数和查询结果只表达实际值；成人榜单保持原站独立顺序，不跨源混合名次。 | 审美库15系统「缺测/零/过期」；ScopedBrowseController / ProfileSiteShelf 实际回执。 | 部分源失败时可独立重试，不能把未知显示为0或已完成。 |
| 任务反馈与恢复 | 登录、收藏读取、分页、错误、恢复贴近当前对象；保留已有结果和单源重试，离页取消只取消意图级工作。 | 根页任务反馈与恢复；SourceCapabilityUi 的 owner fences、ProfileSiteShelf 的账号身份校验。 | 切源或账号变化后旧请求不能污染当前列表；已完成内容不被全屏失败替代。 |

## 验证边界

遵守当前 MangaFlow 项目流程：只读源码与 diff，不运行测试、编译、本地构建、设备探针或 UI 自动化。最终报告的15项均需分别列实际代码落点和待设备体验条件；源码已实现不能标记运行／视觉通过。

## 本批实现落点与保留边界

来源浏览现为一条对象明确的上下文工具栏；分类、热门标签与筛选各进一个既有 MotionBottomSheet。少量筛选值直接并列，更多选项和多选仍转入完整列表，转场继续等待真实退出再执行。来源选择按「浏览来源／登录后浏览／待处理」分组；这表达本机状态和已知错误，不保证站点在线。

成人聚合推荐的画廊由真实目录决定固定框架，封面解码不再触发向页面顶部插入内容。搜索与成人详情标签采用中性色，搜索标签为12sp并保留44dp触控范围；详情先说明来源，首屏保留六个标签及查看全部入口。原始标签路径、作者搜索和全部标签内容保留。章节分组与站点收藏夹的触控高度也提升到44dp。书架显示实际来源身份和已加载收藏数，分页未结束以「+」表示而不伪装总量。

登录／注册与凭据方式沿用已采用的 Ovio 控件，单一登录能力保持单一展开入口，重复点击当前方式不清空输入。明确的收起动作仍清除凭据输入。账号取消、注册同意、来源代次、秘密存储、站点收藏所属账号与分区历史均沿用原有实现。评论重新分离作者、正文与来源／时间／点赞信息，既有读取和分页行为未改。

`DiscoverScreen.kt` 同时重排原生 Copy 榜单行：68×98dp封面、稳定名次轴、标题与作者相邻，指标继续由同一个 RankingMetrics 提供；没有重算名次或改变周期／分页。

涉及10个UI文件：`AdultZoneScreen.kt`、`ContentProfileControls.kt`、`SourceCapabilityUi.kt`、`SourceAccountControls.kt`、`DiscoverScreen.kt`、`SearchScopeBar.kt`、`SearchScopeControl.kt`、`LibraryScreen.kt`、`DetailScreen.kt`、`DetailCatalog.kt`。`ProfileSiteShelf.kt` 仅阅读，账号归属、恢复和收藏数据契约保持原样。

源码复查包含改动diff、回调签名、commonMain兼容写法与 `git diff --check`。全部15系统的设备／运行／视觉状态仍为**未验证**，由本批总设计文档汇总具体回查动作。
