# 阅读缓存生命周期：范围、容量、过期分别负责什么

## 事实与迁移

旧实现对活动阅读章节整体保护，超过前读/回看范围只会退出准备队列，不等于删缓存。内存是 Coil 可复用解码 LRU；磁盘是可再生成原图/衍生图片，离线章节不属于这个可清理存储。范围淘汰不再通过改数字或仅增加一个 UI 开关模拟。

新增 `contentCache.memoryOutsideWindowCleanup` 和 `diskOutsideWindowCleanup`，分别控制两种范围回收。内存缺省 true（旧配置缺字段也启用，只减少解码复用）；磁盘缺省 false（保留原图，避免升级后突增重复联网）。已明确保存的 false/true 均尊重。旧配置容量与过期策略保持，不清用户存档，不改离线目录，不重写缓存索引版本。

## 四种不同动作

| 动作 | 内存 | 磁盘 |
| --- | --- | --- |
| 离开阅读范围 | 可选移除已识别的可复用解码条目 | 可选删除已识别的可再生成图片 |
| 达到容量 | 既有硬容量及 LRU 继续生效 | 硬容量、写入准入继续生效；现有协调清理按配置顺序选择 |
| 未使用到期 | `memoryIdleMinutes`，0 表示不额外按时间清理 | `imageRetentionHours`，0 表示不额外按时间清理 |
| 手动清理 | 移除复用条目，不销毁显示者持有的图像 | 仍逐项验证版本、访问和保护条件，不强删使用中的资源 |

现有 `automaticCleanup` 控制磁盘协调器的过期/容量回收，不控制新范围清理。关闭范围清理只停止“离窗”这一触发，容量/到期仍可回收安全的窗外条目。关闭 `automaticCleanup` 也不等于关闭 Coil 的硬容量上限，不能把相关 UI 写成无限缓存。磁盘淘汰顺序不代表内存也有相同可选顺序。内存范围回收计入独立 `rangeEntries/rangeBytes`，不伪装成人工清理或容量淘汰。

## 范围的真实定义

活动阅读布局发布当前可见页、主方向前读、回看、独立解码准备、仍由布局持有的图像和已提升前台任务的并集；主方向使用两逻辑页意图策略，因此单页回看不会立即把长窗翻侧。额外仍被解码/前台使用的页可以晚于数字范围回收，不能为满足页数强删它们。

每个阅读会话以精确缓存身份登记身份到页集合，一张共享图片可对应多个页。当前完整 manifest 登记之前保守保护整章；持久索引中的单个 pageIndex/chapter 字段只是说明，不能单独授权删除。只有当前会话实际进入过保留窗口的身份才成为范围回收候选。离开会话仅撤销其保留，并交接这些已识别候选，不扫描清空整章。

HTTP 图片由当前 manifest 的请求缓存 key 登记；脚本/JM 文件先有实际文件租约描述，再由当前阅读 owner 的真实解析/加载结果授权范围映射。旧后台 manifest 或租约不能给新会话标记 ready 或取得删除权限。未知身份、未知页、未知所属映射继续保留。其他阅读会话、来源修复/准备会话仍按其保护保留同一资源。缓存 key 保留来源、账号会话、请求头和转换身份，不能按裸页码/文件名猜测跨源相等。

## 删除前的安全门

范围清理和容量回收共用文件所有权保护。每次实际删除再次验证：当前开关、是否仍在范围外、全部会话保留并集、真实文件租约、下载任务、最近访问交接保护、文件时间/长度/原记录访问时间。Coil 的原图快照和 editor 也必须释放才可删除；离线文件根本不在可选后端中。

内存只调用缓存的精确 key remove，不 close/回收显示者、解码器、原生层持有的对象。最近 30 秒复用过的条目保留，当前会话保留的 key 不参与。磁盘原图消失后，已知内存别名仍可由独立内存策略回收，不把两开关绑在一起。

## 时机和用户代价

窗口/文件租约变动唤醒维护，纯内存范围变动走独立轻量任务，不为了每次翻页扫描整个磁盘目录，现有约 1.5 秒合并调度不变；最近访问/文件交接保护约 30 秒，保护结束后再尝试。活动采样亦最多每分钟补查一次。因此“离开范围”表示成为可安全回收候选，不保证下一帧立即清零。当前使用、在途、离线和未知归属不会为了达到数字而被强删。

开启磁盘范围清理后，回看超出保留范围的页可能需要重新联网取得原图，并重新解码。只清内存通常可从磁盘重新解码，不必联网。缓存字节减少不等于进程 RSS 立即下降；画面对象可继续由显示层持有。

## 验收边界

本片未运行本地构建、自动测试或设备验收。合并前静审；之后需验证单页回看/长跳/换章、双页、模式交接、相同 key 多页、多会话、来源替换、下载抢占、未知归属、关闭开关期间的在途清理、文件版本变化、离线保留、两开关各自开启及容量/到期的独立触发。不能把静审或计数变化当成实际无重传证据。

## 后续：设置变化时停止旧自动批次

自动过期/容量扫描使用同一配置快照（开关、TTL、预算及对应发布世代）。实际删除前再次核对，不把旧扫描候选套用到新设置。Coil/普通文件在删除门禁检查；资料缓存 owner 在自己的文件锁与身份校验后检查；番剧缓存每个 span 检查。番剧本轮候选上限不会提前发布，最终经配置锁原子校验后才成为新的硬上限；失效则保留上一已发布上限并唤醒新维护。

这是阻止尚未开始的旧自动删除，不是回滚已准入的单项删除。手动清理仍使用用户确认过的快照和原有使用/身份保护，不受自动批次配置门禁控制。原生已发布硬容量限制仍存在，关闭自动协调清理不等于无限缓存。

关闭磁盘范围清理后，窗口移动若释放了受保护资源且最近测得容量已达上限，仍会唤醒容量维护。没有容量压力时，纯内存窗口更新不额外扫描磁盘。此改动不改阅读器或跨模式原图所有权；仍未进行本地构建、自动测试或设备时序验收。
