# GLASS-ROLES-06 · MangaFlow 固定玻璃材质设计

日期：2026-11-13。原则：不提供「毛玻璃 / 液态玻璃」全局皮肤切换。材质按组件的交互职责固定，不随漫画、阅读底色或壁纸主题变化而切换。

## 漫画线稿、海报和触点 · 2026-11-24

用户反馈“我们的液态玻璃其实做的还是不够好吧没有苹果那种感觉”。阅读器两块玻璃里各有一层 48% 的主题底色，首页当前标签使用渐变色块。材料是否成立，要看漫画的黑线或海报的色边从控件下面经过时，以及手指按下、移动和松开时各发生什么。[Apple WWDC25 · Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)

- 小按钮保留清晰中心、轻微折射和左上方的局部反光。按下时光落在触点，材料轻压并回弹，文字和触控范围稳定。
- 导航与阅读坞各做一次材质调色。随控件短边增加，背景扩散从 8 dp 过渡到 17 dp。阅读画布、封面或页面内容已有明确归属时直接选中该来源。菜单和设置继续使用适合长文的毛玻璃。
- 正式软件需复看三种场景：滚动番剧封面经过顶栏并切换标签，在一张黑白页和一张彩页上呼出阅读工具，以及横屏实播时展开控件。分别看边缘是否随内容变化、正文和字幕是否清楚、按压是否跟手。保存代码和触发构建后，这三项仍需真机反馈。

实现参照为 Haze 2.1.0 同一版本的 [GlassOptics](https://github.com/chrisbanes/haze/blob/ca21ff2060e52e1882afdb94f9b055f7fc834bd9/haze-glass/src/commonMain/kotlin/dev/chrisbanes/haze/glass/GlassOptics.kt)、[HazeInput](https://github.com/chrisbanes/haze/blob/ca21ff2060e52e1882afdb94f9b055f7fc834bd9/haze/src/commonMain/kotlin/dev/chrisbanes/haze/HazeInput.kt) 与[触摸响应](https://github.com/chrisbanes/haze/blob/ca21ff2060e52e1882afdb94f9b055f7fc834bd9/haze-glass/src/commonMain/kotlin/dev/chrisbanes/haze/glass/GlassInteraction.kt)。

## 发现页的分组与选中态 · 2026-11-27

左侧菜单、中间分类、右侧历史与搜索各用一块接近主题色的半透明底。组间露出封面，每组外侧留一层向下散开的柔影。封面滚过时只在组的边缘产生轻微折射，高光集中在迎光的一侧。

分类标签在同一块玻璃上绘制。切到「更新」时，浅色块沿原有弹簧轨迹移到文字下面，字重同时加深。深色模式使用轻微提亮的色块，减少透明度时使用实色，增强对比度时进一步拉开明度，键盘焦点有独立提示。

## 页面布局

- **首页 / 发现**：三组导航分别使用小面积液态玻璃；搜索图标展开时由 Clear 到 Regular 的视觉组织，但仍以同一搜索状态控制动画。轮播完整展示封面，文案利用局部渐变和新 GALLERY 氛围材质，热度最多一行，遮不住封面。
- **书架 / 更新 / 下载**：顶栏液态玻璃。封面卡片、列表主体、章节网格是低对比实色或背景材质，不为每行重复折射。筛选与上下文菜单使用毛玻璃。
- **详情**：按用户最新要求，顶部扩大为约七成竖屏空间，用 DETAIL_HERO 单层液态玻璃承载左清晰封面、右标题作者和通栏标签评分；长内容自然增高并沿原滚动关系退出。封面背景模糊弥散，短操作清透液态；章节状态保持原有可读表面，继续阅读坞不改。
- **阅读器**：漫画像素本身不玻璃化；上下控制栏为 Regular 液态玻璃；设置与长文面板毛玻璃；阅读底色、双页与保持常亮仍可调整。

## 技术边界

- 当前实现以 `DESIGN.md` 的 GLASS-PIPELINE-07 为准：API 33+ 的毛玻璃和液态玻璃都适应实际背景，毛玻璃仍为零折射；搜索和分类菜单厚度跟随既有展开进度。发现页相关导航/操作共用两成员光学场，静止保持分段，按压时仅相邻成员可形成局部连接；左侧菜单始终独立。旧备份规则及下述固定职责不变。
- 保留 Haze 背景采样、Haze Glass 光学路径、当前低对比柔影、连续圆角以及已有动效。不得叠加多个光学 Shader 或给内容卡片逐层增加玻璃。
- 对清透按钮使用局部高光和短暂触摸形变；对长文字及面板用更高漫散射。玻璃内的按钮和文字不再额外创建同层玻璃。
- 低于 API 33、无法采样、软件绘制、禁用动效及首帧情况保留毛玻璃或稳定表面回退，确保操作区域和文本可读。
- 旧备份 JSON 的 `glassSkin` 字段可以存在但直接忽略。新偏好不再写入这一字段，两个设置选择入口及选择器源码移除。
- 按 AGENTS.md 不写/不跑测试，不在本地构建，直接最新 main 并确认 CI 已触发。真机材质与动画效果以用户实际验收为准。
