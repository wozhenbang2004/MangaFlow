# GLASS-ROLES-06 · MangaFlow 固定玻璃材质设计

日期：2026-11-13。原则：不提供「毛玻璃 / 液态玻璃」全局皮肤切换。材质按组件的交互职责固定，不随漫画、阅读底色或壁纸主题变化而切换。

## 固定角色表

| 角色 | 固定材质 | 场景 |
| --- | --- | --- |
| CONTROL | 清透液态玻璃 | 小型悬浮按钮、收起的搜索入口 |
| ARTWORK | 清透液态玻璃 | 封面浮动操作，封面色彩轻微透入边缘 |
| NAVIGATION | 常规液态玻璃 | 三组分段顶栏、展开后的搜索栏、阅读器上下工具栏 |
| THUMB | 清透液态玻璃 | 进度条活动指示；触控目标大于视觉小圆点 |
| READING_DOCK | 常规液态玻璃 | 详情页的继续阅读悬浮条；文本区域优先扩散而非折射 |
| GALLERY | 局部低折射氛围液态玻璃 | 首页封面画廊的图文融合区；保留最新 GALLERY 专用参数，避免大黑胶囊 |
| PANEL | 毛玻璃 | 阅读设置、章节面板、长内容浮层 |
| POPOVER | 毛玻璃 | 多行菜单、评论过滤和局部操作面板 |
| DRAWER | 毛玻璃 | 全高侧栏；保留环境色与壁纸连续性 |

## 页面布局

- **首页 / 发现**：三组导航分别使用小面积液态玻璃；搜索图标展开时由 Clear 到 Regular 的视觉组织，但仍以同一搜索状态控制动画。轮播完整展示封面，文案利用局部渐变和新 GALLERY 氛围材质，热度最多一行，遮不住封面。
- **书架 / 更新 / 下载**：顶栏液态玻璃。封面卡片、列表主体、章节网格是低对比实色或背景材质，不为每行重复折射。筛选与上下文菜单使用毛玻璃。
- **详情**：封面上的短操作清透液态；标题、作者、评分、标签和章节状态保持稳定可读表面；继续阅读为浮动 Regular，按压时给轻微形变和边缘光。
- **阅读器**：漫画像素本身不玻璃化；上下控制栏为 Regular 液态玻璃；设置与长文面板毛玻璃；阅读底色、双页与保持常亮仍可调整。

## 技术边界

- 当前实现以 `DESIGN.md` 的 GLASS-PIPELINE-07 为准：API 33+ 的毛玻璃和液态玻璃都适应实际背景，毛玻璃仍为零折射；搜索和分类菜单厚度跟随既有展开进度。发现页相关导航/操作共用两成员光学场，静止保持分段，按压时仅相邻成员可形成局部连接；左侧菜单始终独立。旧备份规则及下述固定职责不变。
- 保留 Haze 背景采样、Haze Glass 光学路径、当前低对比柔影、连续圆角以及已有动效。不得叠加多个光学 Shader 或给内容卡片逐层增加玻璃。
- 对清透按钮使用局部高光和短暂触摸形变；对长文字及面板用更高漫散射。玻璃内的按钮和文字不再额外创建同层玻璃。
- 低于 API 33、无法采样、软件绘制、禁用动效及首帧情况保留毛玻璃或稳定表面回退，确保操作区域和文本可读。
- 旧备份 JSON 的 `glassSkin` 字段可以存在但直接忽略。新偏好不再写入这一字段，两个设置选择入口及选择器源码移除。
- 按 AGENTS.md 不写/不跑测试，不在本地构建，直接最新 main 并确认 CI 已触发。真机材质与动画效果以用户实际验收为准。
