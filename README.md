# 漫流 · MangaFlow

一个专注于阅读的 Android 漫画客户端。使用 Kotlin 和 Jetpack Compose，支持 Android 8.0 及以上。

[下载最新版本](https://github.com/wozhenbang2004/MangaFlow/releases/latest) · [构建与发布](https://github.com/wozhenbang2004/MangaFlow/actions/workflows/android-release.yml)

## 功能

- 漫画推荐、日／周／月／总热榜、最近更新、搜索、沉浸式详情与章节目录，公开阅读通过拷贝漫画匿名来源获取。
- 纵向滚动、从左至右和从右至左翻页，图片缩放，阅读底色、亮屏和页间留白设置。
- 本地书架、每章独立的阅读进度和长图位置，从历史记录直接继续阅读，目录在后台加载。
- 相邻图片预加载、短期章节缓存和临近章末的下一章准备，图片沿用已有磁盘缓存。
- 官网网页登录、个人 Cookie / Token 导入与账号密码登录，云端收藏、云端章节记录和收藏同步。
- 章节下载、暂停与继续、失败重试、离线阅读；后台任务由 WorkManager 管理。
- 详情页以紧凑站点标记并列显示拷贝热度、Bangumi 十分制和 AniList 百分制评分，保留各站评分人数与出处。
- 拷贝作品评论与回复、Bangumi 中文短评、AniList 长评正文分页阅读；多义条目先区分漫画与小说，再按作者和别名匹配，无法唯一确认时可选择并记住关联。
- 每章末尾显示拷贝本章讨论，竖向阅读和左右翻页均可进入；评论不计入漫画页数，续读仍定位到正文。
- 应用内检查更新、更新提醒、安装包断点续传与覆盖安装。

第三方来源的错误、限流和条目未匹配会直接显示，不使用示例漫画或虚构评论填充。

## 推荐、热榜与讨论

发现页的推荐使用拷贝公开推荐列表；热榜可切换日、周、月、总榜与男频／女频，保持来源的排序。日榜表示上升最快，列表数字统一标作热度，不将它解释为该时间段的阅读人数。最近更新按来源更新时间排列。当前没有将来源推荐包装成个人化推荐。

详情页先展示站点数值和少量评论；点击站点切换口碑，展开后分页阅读。拷贝评论中的 `count` 表示回复数，展开时读取对应评论的回复。评分、评论及匹配失败分别显示，一站失败不会把其他站的内容抹掉。

章节讨论只使用当前章节 UUID。Bangumi 与 AniList 的作品短评／长评保留在作品详情，不混进本章讨论。长评正文默认按可能剧透折叠，用户可以主动展开；来源没有明确剧透标记的普通评论不保证没有剧透。

## 账号与匿名阅读

从侧栏的 **账号与云端**，或书架右上角的 **云端书架** 进入登录页面。**官网登录** 打开拷贝自己的登录页面，完成后将登录状态交给应用验证。网页登录会话结束时清理临时 Cookie 和网页存储，应用仅在账号资料验证成功后保存个人 Token。

也可以粘贴自己的完整 Cookie、`token=…`、`Token …`、`Authorization: Token …` 或单独的 Token，或使用账号密码登录。输入只在当前页面内存中停留，提交后清空。来源返回 210 时保留其具体提示并隐藏凭据，不把所有 210 都解释成账号受限；来源要求等待时仍遵守重试时间。

公开搜索、详情、目录、正文、图片和下载使用独立匿名客户端。网站为当前匿名访问设置的临时 Cookie 只留在该次会话；个人 Token 只用于固定的个人资料、收藏和云端章节记录接口。

登录后可分页浏览云端收藏和阅读记录。在详情页变更本地收藏时会同步这次操作；同步失败保留本地结果，并在账号页提供重试。云端书架中的移除操作仅修改云端收藏。正文图片已出现在阅读视口后，才异步同步当前章节，账号接口失败不会阻塞阅读。

云端记录精确到章节，本机保存页码、滚动偏移和长图内部位置。退出账号会清空当前账号和云端列表，保留本地书架、阅读进度与已下载章节。

历史记录直接打开上次阅读的章节和位置；已下载章节优先离线读取。完整目录在后台补齐，失败时可在阅读器目录中重试。相邻页预读只准备小范围图片，临近章末才准备下一章，离开阅读器时取消无用请求。首次阅读和网络较慢时仍可能需要等待图片下载。

## 构建

环境：JDK 17、Android SDK 35、Build Tools 35.0.0。Gradle 8.9 Wrapper 已包含在仓库中；Android Studio 可直接打开根目录。

```bash
./gradlew :app:assembleDebug
```

调试包位于 `app/build/outputs/apk/debug/app-debug.apk`。正式包由 GitHub Actions 使用固定发布密钥签名；本地调试包的签名不同，不能覆盖正式版。

流水线只负责编译、打包、签名和发布，不运行测试或 lint，不新增自动测试套件。来源接入按授权核对真实 API；构建成功、服务链路验证和 Android 真机体验分别记录，不互相替代。

功能分支的 **Android build** 仅编译调试 APK，供集成前核对编译结果；进入 `main` 后仍走原有固定签名的发布流程。接入新来源前允许用户要求的有界真实匿名 API 读取，不添加自动测试套件。

## 自动发布

推送到 `main` 或手动启动 **Android release** 后，流水线会：

1. 为本次运行分配 `0.1.<run_number>`，`versionCode` 为 `10000 + run_number`。
2. 编译 release APK，并使用同一份 PKCS12 密钥签名。
3. 生成签名更新清单 `latest.json` 和 `SHA256SUMS`。
4. 上传完整资产后发布 GitHub Release，供用户直接下载和应用匿名检查更新。

已发布的同一次运行重跑会保留原资产。发布前后核对源提交与 tag；旧构建不会覆盖新的 `main` 版本。

仓库 Actions Secrets 使用 `MANGAFLOW_SIGNING_KEYSTORE_B64` 与 `MANGAFLOW_SIGNING_PASSWORD`。首次建立签名身份时，可运行 `scripts/create-signing-key.py`，参数为仓库外的私密目录。密钥 alias 为 `mangaflow`；发布后需要持续保留同一密钥及密码。

客户端使用当前安装包的签名证书验证更新清单，再核对 APK 大小、SHA256、包名、版本和签名，最后由 Android 系统确认安装。自动检查周期为六小时，具体调度受系统后台策略影响。

## 代码结构

| 目录 | 职责 |
| --- | --- |
| `data/` | 匿名来源请求、漫画与章节解析、评分和评价匹配 |
| `account/` | 加密账号凭据、个人接口、收藏和云端章节同步 |
| `storage/` | 本地书架、阅读偏好、持久下载队列 |
| `reader/` | 滚动与分页阅读、图片缩放、进度记录 |
| `ui/` | 导航、发现、详情、下载与设置 |
| `update/` | 版本检查、通知、下载校验与安装 |
| `scripts/` | 签名身份创建与发布资产生成 |

Android 源码位于 `app/src/main/java/dev/mangaflow/`。图片加载使用 Coil，缩放使用 Telephoto，玻璃材质使用 Haze。

## 数据与来源

应用不提供自建用户服务或统计 SDK。个人 Token 由 Android Keystore 的 AES/GCM 密钥加密后保存在应用私有空间，密码不保存，退出时删除凭据与对应密钥。账号请求直接访问拷贝漫画的固定个人接口；书架、页内阅读进度、偏好和下载保存在设备上。漫画、评分、评价与应用更新请求直接访问各自来源。仓库不包含漫画文件、个人数据或签名私钥。

漫画和评价内容归其原作者及来源所有，详情与评价保留原站入口。请按来源的使用规则阅读和保存内容。
